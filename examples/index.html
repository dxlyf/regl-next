regl-next examples

从三角形到 WebGL2

这些示例覆盖 regl 的常见使用场景：命令、动态值、batch、scope、 elements、texture、framebuffer、3D、UBO、sampler object 与实例化。 每个页面都可以直接在浏览器中打开，源码在页面内可读。

npm run build  →  打开 examples/index.html
